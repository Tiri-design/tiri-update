How to update

  1. Use Chrome, Edge or Firefox (version 151 or newer) on a computer. On Safari or a phone: see Update with a file below.
  2. Plug the hub into the computer with a USB-C data cable (some cables only charge).
  3. Press Connect and choose USB JTAG/serial debug unit in the list.
  4. Press Update. Don't unplug the hub while it writes; it says when it's done.

Tag names and settings are kept. If an update is interrupted, plug the hub in again and repeat: nothing is lost.

Update with a file

Any browser works, Safari too, on a Mac, a Windows PC or Linux. For hubs with version 0.29 or newer (the version is at the bottom of the hub's Settings).

  1. Download the update fileNo update file available yet.
  2. On the hub: Settings (the dots, top right), then Hub, then Update the hub.
  3. Plug the hub into the computer with a USB-C data cable. A drive called TIRI-HUB appears.
  4. Drag the file onto TIRI-HUB. The hub checks it and restarts. Done.

Your computer may say the drive was removed without ejecting: that's fine. Tag names and settings are kept. A wrong or damaged file changes nothing: the hub says so. If a new version doesn't start, the hub goes back to the one before by itself.

Hubs older than 0.29: update once with Chrome, Edge or Firefox above. After that, files work too.
