TiriHub update

Update your Tiri hub

It takes about two minutes. Your tags, names and weekly plan stay just as they are.

Looking for the latest version…

What's new in this version
  • Updating all your tags at once is easier. Shake them near the hub and it starts by itself, showing how far along each tag is.
  • A tag with a low battery waits for a fresh one before it's updated, so a tired battery can't leave it stuck.
  • Packing at the door opens the list on its own, and the hub shows when the bag is being moved.
  1. 1

    Plug in your hub

    Connect it to this computer with a USB-C cable. It can stay on the wall if the cable reaches.

    Some cables only charge. If your hub doesn't show up in the next step, try another cable.

  2. 2

    Connect

    Press the button. A small window opens. Pick USB JTAG/serial debug unit (that's your hub) and press Connect.

    Firefox asks once whether this page may use USB devices. Allow it.

  3. 3

    Update

    Leave the cable in until you see All done. The hub's screen goes dark for a few seconds while it restarts. That's normal.

    Getting ready…

    If it stops halfway, nothing is lost. Plug the hub back in and start again.

✓

All done

Your hub is up to date. You can unplug it.

Prefer a file, or no USB here? Update with a file instead

Update with a file

Works in any browser, Safari too.

  1. Download the update fileThere's no update file right now.
  2. On the hub, open Settings (the dots, top right), then Hub, then Update the hub.
  3. Plug the hub into your computer with a USB-C cable. A drive called TIRI-HUB appears.
  4. Drag the file onto TIRI-HUB. The hub checks it and restarts by itself.

That's it. If your computer says the drive wasn't ejected properly, you can ignore it.

Having trouble?

My hub isn't in the list

Most often it's the cable: some USB-C cables only charge. Try another one, or another USB port.

If this page is open in another tab or window, close that one, unplug the hub, plug it back in and press Connect again.

The update stopped halfway

Nothing is lost. The update never touches your tags, names or settings, and the hub can always be updated again. Unplug it, plug it back in and start again from Connect.

My computer says the drive wasn't ejected

That's expected when you update with a file. The hub restarts as soon as it has the file, so you can ignore the message.

The new version didn't start

The hub goes back to the version it had before, by itself, and tells you so. Try the update once more. If it happens again, write to us.

My hub is older than version 0.29

Older hubs can't take the file yet. Update once from this page in Chrome, Edge or Firefox; after that the file works too. You'll find the version at the bottom of the hub's Settings.
